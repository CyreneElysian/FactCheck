# 待联网完成：分享卡片二维码（P3-38）

> 状态：**唯一剩余项**。产品文档 §4.13 要求分享卡片含二维码，本机环境无法完成，原因与方案如下。

## 为什么本机做不了

二维码需要一个**编码实现**，而三种来源全部不可用（均已实测）：

| 来源 | 结论 |
| --- | --- |
| npm `qrcode` | registry 超时；本地 npm 缓存 `ENOTCACHED` |
| Maven `com.google.zxing:core` | 离线仓库 `mvn_repo` 中不存在 |
| Python `qrcode` / `segno` / `pyzbar` | venv 中均未安装 |

**为什么不手写一个二维码编码器**：QR 编码涉及 Reed-Solomon 纠错、掩码选择、格式信息与版本信息，
任何一位算错的结果都是"看起来像二维码但扫不出来"。本机既没有参考实现可以逐位比对，
也没有解码器可以反向验证——**写一个无法验证的编码器，比不写更糟**（它会把问题伪装成已完成）。
因此当前降级为"在分享卡片上打印可访问链接"，联网后按下面任一方案补齐。

## 方案 A（推荐）：后端出图，前端只贴图

不引入任何前端依赖，且**可被自动化测试验证**（编码后立刻解码，断言内容一致）。

1. 加依赖（`fact-check/pom.xml` 的 `dependencyManagement`）：

```xml
<dependency>
  <groupId>com.google.zxing</groupId>
  <artifactId>core</artifactId>
  <version>3.5.3</version>
</dependency>
<dependency>
  <groupId>com.google.zxing</groupId>
  <artifactId>javase</artifactId>
  <version>3.5.3</version>
</dependency>
```

2. 新增 `QrCodeUtil`（放在 `fact-check-common/.../util/`）：

```java
public static byte[] png(String text, int size) throws Exception {
    BitMatrix matrix = new QRCodeWriter().encode(text, BarcodeFormat.QR_CODE, size, size,
            Map.of(EncodeHintType.CHARACTER_SET, "UTF-8", EncodeHintType.MARGIN, 1));
    ByteArrayOutputStream out = new ByteArrayOutputStream();
    MatrixToImageWriter.writeToStream(matrix, "PNG", out);
    return out.toByteArray();
}
```

3. 新增接口（`CommonController`，需登录——顺带把 `/common/**` 加进用户端拦截器的路径模式）：

```java
@GetMapping(value = "/qrcode", produces = MediaType.IMAGE_PNG_VALUE)
public byte[] qrcode(@RequestParam String text) throws Exception {
    ValidationUtils.requireText(text, "二维码内容", 300);
    return QrCodeUtil.png(text, 240);
}
```

4. 前端把图片画到分享卡片上（`HistoryDetailView.drawShareCard`，替换当前打印链接的那两行）：

```ts
const img = new Image()
img.src = `/api/common/qrcode?text=${encodeURIComponent(shareUrl.value)}`
await img.decode()
ctx.drawImage(img, canvas.width - 140, 300, 100, 100)
```

5. 测试（离线可跑，`mvn test`）：

```java
@Test
void qrcodeShouldRoundTrip() throws Exception {
    byte[] png = QrCodeUtil.png("https://example.com/history/1", 240);
    BufferedImage image = ImageIO.read(new ByteArrayInputStream(png));
    Result result = new MultiFormatReader().decode(
            new BinaryBitmap(new HybridBinarizer(new BufferedImageLuminanceSource(image))));
    assertThat(result.getText()).isEqualTo("https://example.com/history/1");
}
```

## 方案 B：前端装 `qrcode`

```bash
cd fact-check-web
npm i qrcode
```

`HistoryDetailView.drawShareCard` 里改用：

```ts
import QRCode from 'qrcode'
await QRCode.toCanvas(qrCanvas, shareUrl.value, { width: 120, margin: 1 })
```

代价：多一个前端依赖（约 40KB）、且**没有自动化验证手段**（只能人眼扫）。
如果只是为了分享卡片，方案 A 更划算。
